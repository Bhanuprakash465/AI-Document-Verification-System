# AI Document Verification System

An AI-powered document verification system that extracts, validates, and verifies information from identity documents using Computer Vision, OCR, and Large Language Models (LLMs).

## Features

- Upload document (JPG, PNG, PDF)
- Image preprocessing using OpenCV
- OCR-based text extraction
- AI-powered document verification
- FastAPI REST API
- React frontend (Coming Soon)

## Tech Stack

### Backend
- Python
- FastAPI
- Uvicorn

### AI & Machine Learning
- OpenCV
- PaddleOCR
- Hugging Face Transformers
- LangChain
- Llama 3

### Frontend
- React
- Tailwind CSS
